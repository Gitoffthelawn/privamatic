# STATE archive

`STATE.md` at the repo root keeps only the last three runs, so that it stays under about 150 lines.

Older runs move here:
- **One file per month:** `YYYY-MM.md`, for example `2026-10.md`. A run goes in the file for the month it was done.
- **Move runs whole and unedited.** Keep the heading, the checkboxes and the evidence. Put the newest run at the top of the file.
- **Open items:** if a moved run still has an unticked item that matters, copy it to `Next` or `Open questions` in `STATE.md` first.
- **No rewriting:** the archive is history. Don't edit a run after it is archived. Corrections go in a new run in `STATE.md`.
